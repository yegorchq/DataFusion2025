### Описание
Этот репозиторий содержит решение для задачи "Label Craft" соревнования [Data Fusion Contest 2025](https://ods.ai/competitions/data-fusion2025-labelcraft).

### Структура проекта

- **Labelling_LLM.ipynb** - jupyter-ноутбук для доразметки данных с помощью большой языковой модели, поднятной на локальном сервере. В моем решении использовалась модель Qwen2.5:3b.
- **Training.ipynb** - jupyter-нотубук для обучения модели с валидацией и без.
- **pipeline.py** - скрипт для предобработки данных.

- **data/raw** - папка с сырыми данными (содержит исходные данные от организаторов соревнования)
- **data/processed** - папка с обработанными данными (содержит данные, получаемые в результате работы pipeline.py и Labelling_LLM.ipynb)

### Предобработка данных
- Разделяем размеченную выборку (labeled_train.parquet) на две подвыборки по принципу размеченности до листовых категорий.
- Доразмечиваем часть неразмеченной выборки (unlabeled_train.parquet) с помощью сопоставления по атрибутам с размеченной выборкой.
- Доразмечиваем выборку с помощью LLM (файл Labelling_LLM.ipynb)
- Генерируем новые объекты для категорий, не представленных в размеченной обучающей выборке.

### Обучение модели
- Для обучения модели используется предобученная русскоязычная трансформер-модель cointegrated/rubert-tiny2, адаптированная под задачу классификации.
- В качестве функции потерь используется кастомная функция потерь Label Smoothing Cross Entropy, учитывающая структуру категорий в виде дерева и применяющая Label Smoothing - "размазывание" метки класса по соседям.
